# Ubiquitous Language

## Purpose

This glossary defines the canonical terminology for the platform so that product, engineering, and operations teams use consistent language over time.

## Terms and Definitions

### Branch
The primary operational customer of the platform. A branch manages supporters, events, communications, and operational workflows.

### Supporter
A person registered within a branch and represented in the platform.

### Member
A supporter who has an active membership product. This is a future capability and should not be treated as the primary concept of the platform.

### Journey
A supporter’s participation in a specific match event, including the operational lifecycle from opening to completion.

### Season
A football season containing journeys, attendance, reporting, and verification windows.

### Verification
A process used to determine whether a supporter is eligible for participation in branch operations or a specific event.

### Eligibility
The current state that allows a supporter to participate in a journey or other operational workflow.

### Event
A match or branch activity that creates an operational workflow.

### Match Participation
The lifecycle of a supporter’s engagement with a specific event.

### Branch Operations
The broader domain that includes supporter management, verification, journeys, communications, reporting, and administration.

## Usage Guidance

- Use these definitions consistently in documentation, discussions, and implementation decisions.
- If a new term is introduced, it should be reviewed against this glossary before being adopted.
- Avoid using overloaded terms such as membership as the primary domain concept when describing branch-led operations.
