# ADR-005 — Platform Engagement Engine

**Status:** Proposed

**Date:** 2026-07-02

**Decision Type:** Architecture

## Context

The Sundowns WPA platform has evolved beyond a membership management system.

Current domains include:

- Authentication
- Branch Management
- Membership
- Payments
- Matches
- Ticketing
- Transport
- Rewards
- Points
- Promotions

Supporter engagement spans all of these domains. Embedding engagement logic inside every Django app would create duplicated code, tight coupling, and inconsistent behaviour.

## Decision

Introduce a dedicated Platform Engagement Engine responsible for reacting to business events generated by other modules.

The Engagement Engine does not own business operations. It consumes domain events and coordinates supporter engagement.

## Architectural Principle

Business modules perform business work.

```text
Membership
    ↓
Activate membership
```

The Engagement Engine reacts afterwards.

```text
Membership Activated
        ↓
Engagement Engine
        ↓
Welcome email
Bonus points
Promotion unlock
Campaign progress
```

## Responsibilities

The Engagement Engine is responsible for:

- Event processing
- Campaign progression
- Engagement scoring
- Notification orchestration
- Promotion triggering
- Behaviour tracking
- Supporter segmentation

It is not responsible for:

- Creating memberships
- Booking tickets
- Processing payments
- Managing transport

## Engagement Rules

Example:

When TicketBooked then:

- Award 20 points
- Send booking confirmation
- Recommend transport
- Recommend merchandise

Another example:

When MembershipActivated then:

- Award activation points
- Welcome campaign
- Unlock member promotions
- Recommend upcoming matches

## Campaign Engine

Campaigns become independent objects.

```text
Attend 5 Matches
        ↓
Progress
        ↓
Reward
        ↓
Badge / Promotion
```

| --- | ---: |

| Book Ticket | 25 |
| Book Transport | 15 |
| Attend Match | 50 |
| Redeem Reward | 20 |

The score is used for:

- Loyalty
- Segmentation
- Campaign targeting
- VIP supporters
- Branch rankings

## Consequences

### Positive

- Loose coupling
- Centralized engagement
- Easier maintenance
- Scalable campaigns
- Better supporter personalization
- Reusable engagement rules

### Negative

- Additional architectural layer
- More implementation effort
- Requires disciplined event design

## Decision Outcome

Accepted.

The Sundowns WPA platform will adopt an event-driven Platform Engagement Engine as the centralized orchestration layer for supporter engagement.

## Implementation Roadmap

1. Create the engagement Django app and event framework.
2. Integrate existing modules to emit domain events.
3. Implement engagement scoring and campaign engine.
4. Add supporter segmentation and notification orchestration.
5. Build operational dashboards for engagement analytics.
