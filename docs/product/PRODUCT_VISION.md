# Product Vision

## Purpose

BranchRoute is being repositioned from a supporter membership platform into an operating platform for student supporters' branches.

The platform should help branches coordinate branch operations around each match, reduce manual administration, and create a persistent digital record of supporter participation.

## Primary Customer

- Student supporters' branches
- Branch administrators and coordinators

## Primary User

- Supporters

## Product Goal

Digitize branch operations for:

- supporter registration
- student verification
- match participation workflows
- transport booking
- complimentary ticket allocation
- ticket collection
- bus boarding
- attendance tracking
- reporting and branch administration

## Strategic Direction

The first release should focus on student branches because they currently rely heavily on manual processes such as Google Forms, manual ticket allocation, repeated verification, and fragmented communication.

The platform should be designed as a foundation for broader expansion into community branches and other supporters' branches in the future.

## Guiding Principles

1. Branch operations come first.
2. Supporter experience should be seamless across the full match-day journey.
3. Operational workflows should be persistent, auditable, and repeatable.
4. Commercial features should be introduced later and remain secondary to branch operations.
5. The architecture should support future growth without forcing a re-platforming exercise.
